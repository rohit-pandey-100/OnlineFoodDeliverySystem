# Online Food Delivery System

A Console-Based Java Project developed using Core Java and Object-Oriented Programming concepts.

## Features

- Customer Registration
- Login
- Restaurant Management
- Food Menu
- Cart
- Order Placement
- Bill Generation
- Payment Module

## Technologies

- Java
- Eclipse IDE
- Git
- GitHub

## Concepts Used

- OOP
- Encapsulation
- Constructors
- Packages
- Objects and Classes
- Collections (Later)
- Exception Handling (Later)
